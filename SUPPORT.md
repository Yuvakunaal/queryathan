# Getting help

- **Something broke?** Open a [bug report](https://github.com/Yuvakunaal/data-cleaning-quest/issues/new?template=bug.yml).
  Say which world and case, which engine (Python or SQL) and what you typed.
- **A question, an idea, or "how do I...?"** Start a
  [Discussion](https://github.com/Yuvakunaal/data-cleaning-quest/discussions).
- **A case whose question, hint or answer looks wrong?** Open an issue with the `content-quality` label.
  Wrong or misleading content is treated as a bug.
- **Want to add a case?** Read [CONTRIBUTING.md](./CONTRIBUTING.md) and the
  [authoring guide](./docs/content-authoring-guide.md).
- **A security problem?** Please do not open a public issue. See [SECURITY.md](./SECURITY.md).
