# World 6 dataset licenses

All files are **CC0** (public domain dedication), synthetic, and generated by
[`scripts/generate-observatory.mjs`](../../../../scripts/generate-observatory.mjs) with a seeded
deterministic PRNG. Names, ids, dates and amounts are invented. Regenerate with
`node scripts/generate-observatory.mjs`; the same script writes the case files and their
expected answers, so data and answer key cannot drift apart.

- `orders.csv`: 150 rows, `order_id, region, product, qty, unit_price, status`.
- `products.csv`: 33 rows, `product_id, category, product, units_sold`.
- `daily-sales.csv`: 60 rows, `day, revenue`, shuffled.
- `users.csv`: 150 rows, `user_id, signup_date`; `activity.csv`: `user_id, active_date`.
- `web-events.csv`: a click log, `user_id, ts, page`, shuffled.
- `shop-events.csv`: an action log, `user_id, device, step, ts`, shuffled.
