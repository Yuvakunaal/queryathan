# World 4 dataset licenses

All four files are **CC0** (public domain dedication), synthetic, and generated by
[`scripts/generate-architect.mjs`](../../../../scripts/generate-architect.mjs) with a seeded
deterministic PRNG. Names and numbers are invented. Regenerate with
`node scripts/generate-architect.mjs`.

- `melt-form.csv`: 12 rows, `product, jan, feb, mar`. Wide, to be melted.
- `pivot-plan.csv`: 30 rows, `store, month, revenue`. Long, to be pivoted.
- `json-vault.csv`: 80 rows, `order_id, payload`. Nested JSON text in one column.
- `the-architect.csv`: 16 rows, `id, region, meta, q1..q4`. JSON metadata and wide quarters together.
