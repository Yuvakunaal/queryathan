# World 7 dataset licenses

All files are **CC0** (public domain dedication), synthetic, and generated by
[`scripts/generate-labyrinth.mjs`](../../../../scripts/generate-labyrinth.mjs) with a seeded deterministic PRNG. Names,
ids, dates and amounts are invented. Regenerate with `node scripts/generate-labyrinth.mjs`; the same script
writes the case files and their expected answers, so data and answer key cannot drift apart.

- `employees.csv`: 60 rows, `emp_id, name, dept, salary`.
- `customers.csv`: 48 rows, `customer_id, name`.
- `orders.csv`: 105 rows, `order_id, customer_id, amount, status`; guest checkouts have an empty customer_id.
- `org.csv`: 40 rows, `emp_id, name, manager_id`; the CEO has an empty manager_id.
- `list-a.csv`: 56 rows, `email`; has repeats and mixed case.
- `list-b.csv`: 48 rows, `email`; has repeats and mixed case.
- `logins.csv`: 592 rows, `user_id, login_date`; some users log in twice on a day.
- `bom.csv`: 31 rows, `parent, child, qty`; a bill of materials for two products.
