# RFC template

Use this for a new world, a new engine, or a breaking schema change. Paste it
into a GitHub Discussion (Ideas category). One page is plenty.

## Problem

What can a learner not do today, or what is painful for contributors? Give one
concrete example.

## Proposal

What would you change? Describe it from the learner's point of view first, then
the technical shape.

## Alternatives considered

At least one other approach, and why you did not pick it.

## Impact

- Content schema or save-file changes (and how old saves keep working)
- Engine, worker or CSP changes
- Accessibility: keyboard path, screen-reader wording, contrast
- Cost: bundle size, startup time, test time

## Open questions

What you are unsure about and would like feedback on.

If the Discussion lands on a decision, it gets recorded as an ADR in
[`docs/adr/`](./adr/).
